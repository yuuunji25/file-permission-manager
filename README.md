# **File permission manager Program**
C를 기반으로 한 사용자별 파일 접근 권한 관리 프로그램
사용자와 파일을 등록하고 각 사용자에게 파일 권한(읽기, 쓰기)을 개별적으로 부여

## 주요 기능
- 사용자, 파일 등록 및 목록 조회
  
- 사용자별 파일 권한 설정 및 권한 확인
  
- 사용자 및 파일 중복 등록 방지
  
- 사용자 및 파일 최대 등록 개수 제한(5개씩)
  
- 파일 입출력을 통한 데이터 저장 및 불러오기 기능
  
- 파일, 전체 데이터 초기화
  
- 초기화 전 확인 절차

## 데이터 관리
- 프로그램 종료 시 사용자 이름, 파일 이름 및 권한 데이터를 access_data.txt에 저장
  
- 프로그램 재실행 시 저장된 데이터를 자동으로 불러오기

## 보완예정사항
- 숫자 이외의 입력에 대한 처리
  
- 중복 권한 설정 안내 기능

11/27 수정사항 
- 사용자별 파일 권한 설정 기능 보완
  
    권한 설정 과정에서 사용자 번호만 입력받고 파일 번호는 구분하지 못하는 문제. 사용자별 파일 권한 설정 수정 필요
  
- 파일 접근 권한 검증 기능 추가
  
    현재 설정된 읽기 및 쓰기 권한이 실제 파일 접근 요청에 반영되지 않음. 접근 허용 및 거부 처리 기능 추가
  
- 파일 데이터 저장 기능 추가
  
    프로그램을 종료해도 등록된 사용자와 파일 정보가 유지되도록 데이터 저장 및 불러오기 기능 추가
  
- 메뉴 반복 출력 문제
    최대 등록 가능 인원 이상 추가 등록을 시도할 경우 메뉴 출력이 반복되는 문제. 원인 확인 필요
  
11/27 수정사항(2)
- 문자열 입력 오류 처리
  
    숫자가 아닌 값을 입력하였을 때 발생하는 입력 오류 수정
  
- 권한 중복 설정 안내
  
    권한을 중복으로 부여하였을 때 설정 안내 메시지가 중복으로 출력되는 문제. 이미 설정된 권한인 경우 중복 설정 안내 메시지 추가
